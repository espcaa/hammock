# hammock

hammock is another slack client experiment! \
i wrote it entirely in go, using [gioui](https://gioui.org/) for the ui! \
it's very instable and i'm not sure if i'll ever expand more on it, so you probably shouldn't use it... (but it was fun learning gioui!)

## installation

just get the latest build from the [actions tab](https://github.com/espcaa/hammock/actions)

## building

you'll need to have go installed, be on macos and run:

```bash
make build-mac
```
